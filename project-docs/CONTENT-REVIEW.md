## How to use this file

1. Edit the wording under **Proposed text**. It starts with the current preview wording; replace it directly rather than keeping several competing versions.
2. Write questions, alternatives or instructions under **Comments**. Comments are for discussion, not for display on the webpage. Comments may be in English or Portuguese.
3. Save your changes in GitHub using **Commit changes**. Then ask in our chat: **“Review the wording file”** or **“Apply the wording file to the preview.”**

Saving this file records a proposal. It does not automatically change the webpage, notify the assistant, or start a background review. On your next request, the latest saved version will be read before proposing or applying changes. Unresolved questions in Comments should be discussed rather than silently treated as approved wording.

This repository is public. Comments are not displayed on the webpage, but remain visible in GitHub and its history. Do not include confidential material.

**Scope:** Explore, section introductions and carousel descriptions, Maker image captions, and article-card titles and summaries. This file does not contain the full article bodies. Use the final section for requests concerning those articles.

**Publishing boundary:** apply approved wording only to `docs/preview/`. Do not replace the existing homepage or add a link to the preview on any existing page. Keep the dark layout, section-first navigation and carousel controls unless a separate change is agreed.

**My perspective**
